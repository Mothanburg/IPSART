# Interferometric and Polarimetric Synthetic Aperture Radar Tools (IPSART)
一个可用于干涉和极化SAR信号处理的MATLAB库。

## 包含模块

### 1. 基础图像处理模块（Basic、Data、SAR）
包含数据读写、图像量化、多视等。

### 2. 干涉SAR处理模块（Geometric、InSAR）
包含卫星轨道管理、像素地理坐标计算、配准、相位滤波等。

### 3. 极化SAR处理模块（PolSAR）
包含极化SAR数据模型、极化分解、无监督分类等。

### 4. 其它模块（Utils）
包含函数式算子等实用工具。
